# Baseline fixa V7

Esta versão do repositório foi congelada como baseline fixa de referência da fase atual do projeto.

## Objetivo
Preservar uma base estável, coerente com o contrato operacional consolidado, para orientar:
- próximas auditorias dos scripts-base;
- próximas implementações controladas;
- futuras alterações validadas de forma organizada.

## Observação
Esta baseline pode evoluir no futuro, mas qualquer alteração deve continuar respeitando:
- o contrato operacional do projeto;
- a auditoria por responsabilidade real;
- a validação local prévia antes de cada entrega.
