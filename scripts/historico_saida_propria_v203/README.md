# Histórico de scripts com saída própria — V203

Este diretório preserva o conteúdo original dos scripts diagnósticos bloqueados
pela governança V203.

Os arquivos aqui são acervo histórico. Eles não têm autoridade operacional, não
devem ser usados para gerar console ou arquivos oficiais e não devem competir
com `nucleo/saida_canonica.py`.


## Governança V204

Os arquivos `.py` deste diretório foram mantidos apenas como marcadores históricos bloqueados.
Eles não têm autoridade operacional e encerram imediatamente com `BLOQUEADO_POR_GOVERNANCA_V204`.
A rota vigente para saídas oficiais é `nucleo.saida_canonica`.
