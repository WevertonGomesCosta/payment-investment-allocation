# Scripts históricos da raiz

Este diretório preserva cópias históricas movidas da antiga raiz de `scripts/`.

Esses arquivos não têm primazia operacional nem diagnóstica sobre os caminhos canônicos atuais. A partir da V203, qualquer script histórico que produza saída própria deve ser tratado como acervo read-only e não deve competir com `nucleo/saida_canonica.py`.
