# Saídas operacionais

Este diretório **não** é o caminho canônico de saídas oficiais da baseline vigente.

Na baseline V186, os caminhos ativos ficam normalizados assim:
- `saidas/oficial/` — artefatos oficiais ativos para leitura, validação e distribuição;
- `saidas/diagnostico/` — artefatos diagnósticos ativos de apoio;
- `saidas/historico/` — artefatos rebaixados, históricos ou de compatibilidade.

`saidas/operacional/` permanece apenas como camada residual de compatibilidade de caminho.
Novos artefatos oficiais **não devem** ser gravados aqui.
