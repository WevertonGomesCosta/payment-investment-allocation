# Workbook operacional principal v2

Este workbook foi reconstruído em formato operacional enxuto, tomando a planilha de referência como base de organização e leitura.

## Abas incluídas
- Resumo
- Extrato
- Recebidos_Aportes
- Plano_Futuro
- Switchings_Propostos
- Switchings_Agrupados
- Justificativa_Switching
- Carteira_Final
- Conferencia

## Objetivo
- mostrar o que já foi realizado;
- mostrar os lotes/recebidos e seus aportes;
- mostrar o que deve ser feito daqui para frente;
- mostrar os switchings propostos e sua versão agrupada;
- explicar por que a carteira foi escolhida e por que o switching foi fragmentado em mais de um dia.

## Observação
A aba `Carteira_Final` é uma visão operacional simplificada para validação. A referência oficial de riqueza terminal continua sendo a baseline v2 confirmada.
